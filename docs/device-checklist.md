# รายการตรวจบนเครื่องจริง (Android tablet และ iPad)

ใช้หลังจากงาน CI ผ่านทั้งสามงาน ติดตั้ง `app-debug.apk` จาก artifact ของ workflow `native` บน Android
และติดตั้งบน iPad ผ่าน Xcode (ต้องเซ็นด้วยบัญชีนักพัฒนาของตัวเอง) แล้วตรวจตามลำดับ บันทึกผล ✅/❌ และรุ่นเครื่อง/ระบบ

| # | สิ่งที่ตรวจ | วิธีตรวจ | ผลที่ถูกต้อง |
|---|---|---|---|
| 1 | กันฝ่ามือ | วางฝ่ามือบนจอแล้วเขียนด้วยปากกา (S Pen / Apple Pencil) | มีแต่เส้นปากกา ไม่มีรอยจากฝ่ามือ |
| 2 | แรงกด | เขียนเบาสลับหนักในเส้นเดียว | ความหนาเส้นเปลี่ยนตามแรงกด |
| 3 | PDF ขนาดใหญ่ | นำเข้า PDF ประมาณ 300 MB แล้วเลื่อนจากหน้าแรกถึงหน้าสุดท้าย | เปิดได้ ไม่ค้าง ไม่ปิดตัวเอง หน้าโหลดตามที่เลื่อน |
| 4 | OCR ภาษาไทย | นำเข้าภาพสแกนเอกสารภาษาไทย รอ OCR แล้วค้นหาคำในเอกสาร | พบคำและไฮไลต์ตรงตำแหน่ง |
| 5 | บันทึกหน้าเว็บที่ต้องเข้าสู่ระบบ | ＋ บันทึกหน้าเว็บ → เข้าสู่ระบบในหน้าต่างบันทึก → บันทึก | ได้เอกสารพร้อมหน้ารับรอง (URL, เวลา, SHA-256) และภาพหน้าจอครบทั้งหน้า ไม่มีช่วงว่างหรือขาว |
| 6 | ปิดภาพในตัวสลับแอป | เปิดเอกสาร แล้วเปิดตัวสลับแอป | ภาพตัวอย่างของแอปถูกปิดบัง |
| 7 | กันจับภาพหน้าจอ (Android) | กดจับภาพหน้าจอขณะเปิดเอกสาร | ระบบแจ้งว่าจับภาพไม่ได้ หรือได้ภาพดำ |
| 8 | เส้นสุดท้ายไม่หาย | เขียนเส้นหนึ่ง → สลับไปแอปอื่นทันที → ปิดแอปแบบบังคับ → เปิดใหม่ | เส้นสุดท้ายยังอยู่ |
| 9 | ติดตั้งใหม่ | ถอนการติดตั้งแล้วติดตั้งใหม่ (ข้อมูลเดิมไม่ถูกกู้คืน) หรือล้างข้อมูลกุญแจเครื่อง → ใส่ PIN | แจ้งว่ากุญแจของเครื่องหายไป และกู้คืนด้วยรหัสกู้คืนได้ |
| 10 | สำรองข้ามเครื่อง | เครื่อง A: สำรองโปรไฟล์ทั้งหมด → ส่งไฟล์ `.pnote` ไปเครื่อง B → กู้คืนโปรไฟล์จากไฟล์สำรอง | เอกสาร โฟลเดอร์ ชุดปากกา และเส้นหมึกครบ ตรวจทั้ง Android → iPad และ iPad → Android |
| 11 | เปิด `.pnote` จากแอปอื่น | แตะไฟล์ `.pnote` ในแอปไฟล์ / LINE / อีเมล → เปิดด้วย PNote | แอปถามให้ปลดล็อกก่อน แล้วถามรหัสผ่านไฟล์สำรอง |
| 12 | ไฟล์ส่งออกไม่ค้าง | ส่งออก PDF และ `.pnote` แล้วกดยกเลิกหน้าแชร์ | ไม่มีไฟล์เหลือในแคชของแอป (ดูขนาดพื้นที่แอปในการตั้งค่า) |
